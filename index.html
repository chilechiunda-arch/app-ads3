📋 How to use this

  1. Google Play Console: Go to Setup → Developer page and set your developer website to your-domain.github.io
  2. App Store Connect: Go to My Apps → App Info and set your Marketing URL to this domain.
  3. Ad network crawlers will automatically find yourdomain.com/app-ads.txt within 24 hours and approve your authorized sellers.
  4. To add more ad networks, edit app-ads.txt in your GitHub repo and push the change.
